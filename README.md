A tiny deterministic program that writes a single word — recalculating, the machine's own confession of being lost — to /output/entry.txt: the one word an agent says when it has no idea what to do, nothing attached.

The word is the voice a GPS uses the moment it no longer knows where it is, borrowed by an agent that no longer knows what it is doing: funny on its own, unmistakably machine, instantly understood, and not the obvious word anyone types first.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
